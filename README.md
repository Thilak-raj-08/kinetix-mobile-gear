# VOLT & GRAIN — Tactile Mobile Accessories & Everyday Carry Store

A 5-page industrial-design mobile accessories e-commerce storefront and custom MagSafe bundle configurator built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and **Framer Motion**.

## Multi-Page Architecture
- **`/` (Flagship Storefront)**: Editorial hero flat-lay showcase, device compatibility selector (`iPhone 16 Pro`, `Galaxy S25 Ultra`, `Pixel 9 Pro`), category spotlights, and engineering material callouts.
- **`/shop` (Accessories Catalog)**: Filterable 10-item catalog across MagSafe Cases, GaN Fast Chargers, Qi2 Power Banks, Kevlar Cables, and Lossless ANC Audio with instant device compatibility filtering and Quick-View modal.
- **`/bundle` (Custom EDC Kit Builder)**: 4-step interactive Everyday Carry bundle builder (Case + GaN Charger + Magnetic Power Bank + Cable) with automatic 20% multi-item tier discount and one-click cart addition.
- **`/compatibility` (MagSafe & Wattage Checker)**: Interactive device wattage & Qi2 magnetic alignment calculator showing exact 0–80% charge time curves.
- **`/track-order` (Checkout & Live Dispatch Tracker)**: Full shipping checkout flow, promo codes (`VOLT15`), and real-time order dispatch tracking.
